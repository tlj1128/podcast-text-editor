# Podcast Text Editor

個人 Podcast 後製輔助工具。開啟音檔後，透過 AI 語音辨識自動產生逐字稿，再用視覺化波形介面快速標記要刪除或靜音的區段，最後一鍵匯出剪輯後的音檔。

> **注意：僅支援 Apple Silicon Mac（M1 / M2 / M3 / M4）**

---

## 功能介紹

### 語音轉文字（轉錄）
- 使用 [mlx-whisper](https://github.com/ml-explore/mlx-examples) 在本機進行語音辨識，不需要網路、不上傳音檔
- 支援 .m4a、.mp3、.wav 格式
- 可設定**提示詞**（節目名稱、人名等），提升特定詞彙的辨識準確率
- 轉錄結果以逐字稿形式顯示，可直接點擊文字跳到對應的波形位置

### 波形編輯
- 視覺化波形，可縮放、捲動
- 在波形上右鍵可標記**刪除區段**（紅色）或**靜音區段**（黃色）
- 標記後可拖曳邊界微調範圍
- 標記重疊時自動合併

### VAD 靜音偵測
- 一鍵自動偵測全片靜音區間（如主持人換氣、停頓）
- 可選擇「確認刪除」或「忽略」每個偵測到的靜音區段

### 逐字稿編輯
- 點擊文字即跳到對應波形位置
- 右鍵可標記刪除或靜音、編輯段落文字
- 贅字標記（嗯、啊、那個…）一鍵高亮顯示

### 匯出
- 匯出剪輯後音檔（.m4a）
- 匯出逐字稿（.txt 純文字 / .srt 字幕格式）

### 自動儲存
- 每次操作後自動儲存進度，下次開啟音檔自動還原所有標記

## 系統需求

| 項目 | 需求 |
|------|------|
| 硬體 | Apple Silicon Mac（M1 / M2 / M3 / M4） |
| 系統 | macOS 13 Ventura 以上 |
| Python | 3.11 或更新版本 |

Intel Mac 不支援，因為語音辨識引擎（mlx-whisper）僅支援 Apple Silicon。

## 安裝步驟

### 步驟一：下載專案

點擊頁面右上角 **Code → Download ZIP**，解壓縮到桌面或任意位置。

### 步驟二：執行安裝腳本

在 Finder 中找到 `install.command`，**按右鍵 → 開啟**。

> ⚠️ 直接雙擊會被 macOS 擋住，**第一次必須用右鍵 → 開啟**，之後就可以直接雙擊了。

安裝腳本會自動完成以下步驟（視網路速度約需 5～15 分鐘）：
1. 安裝 Python 環境
2. 安裝所有相依套件
3. 下載 Whisper 語音辨識模型（約 800MB）

過程中 Terminal 視窗會顯示進度，看到「安裝完成」即可關閉。

### 步驟三：啟動 App

雙擊 `launch.command` 即可啟動。

> 同樣地，第一次需要右鍵 → 開啟。

## 使用教學

### 基本流程

1. **開啟音檔**：選單 `檔案 → 開啟音檔`，選擇錄音檔
2. **轉錄**：選單 `檔案 → 轉錄`，等待 AI 產生逐字稿（依音檔長度需要幾分鐘）
3. **標記要刪除的區段**：在波形或逐字稿上右鍵 → 將此段標為刪除
4. **標記靜音**：右鍵 → 將此段標為靜音（會保留音訊但靜音輸出）
5. **匯出**：選單 `檔案 → 匯出音檔`

### 提升辨識準確率

選單 `設定 → 設定提示詞`，輸入節目名稱、常出現的人名或專有名詞，例如：

```
消業障旅行團 Bryan 台灣
```

下次轉錄時會參考這些詞彙。

### 自動靜音偵測

選單 `編輯 → 偵測靜音區間`，app 會自動掃描全片並標記靜音區段。接著可以逐一選擇「確認刪除」或「忽略」。

## 常見問題

**Q：雙擊 install.command 沒有反應或出現「無法打開」？**  
A：需要右鍵 → 開啟，macOS 對從網路下載的腳本有安全限制。

**Q：安裝需要多久？**  
A：首次安裝約 5～15 分鐘，主要時間花在下載 Whisper 模型（約 800MB）。

**Q：轉錄一集節目要多久？**  
A：依音檔長度而定，M1 上大約是音檔時長的 1/5～1/3，一小時節目約 10～20 分鐘。

**Q：音檔有上傳到雲端嗎？**  
A：不會，所有處理都在本機進行。

**Q：Intel Mac 可以用嗎？**  
A：不行，語音辨識引擎僅支援 Apple Silicon。
